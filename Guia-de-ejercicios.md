# Guía de ejercicios

Aquí explico un poco qué hace cada ejercicio de la UT2 y qué se practica en cada uno.

| Ejercicio | Qué hace | Conceptos |
|---|---|---|
| ej01_par_impar | Dice si un número es par o impar | condicionales, operador % |
| ej02_calificacion | Según la nota te dice si es suspenso, aprobado, notable... | if / elif / else |
| ej03_tabla_multiplicar | Saca la tabla de multiplicar de un número | bucle for, range |
| ej04_adivina | Tienes que adivinar un número aleatorio | while, break, random |
| ej05_menu | Un menú simple con varias opciones | match case |
| ej06_suma_pares | Suma los números pares hasta el que pongas | for, continue |
| ej07_fizzbuzz | El típico FizzBuzz con múltiplos de 3 y 5 | for, condicionales |
| ej08_contrasena | Pide una contraseña y tienes varios intentos | while, else, break, continue |
